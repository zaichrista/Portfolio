Accessibility statement

Last updated: 14 September 2026

This website aims to provide a clear and usable experience for as many people as possible, including keyboard users and visitors using assistive technology.

Using the website

Navigation links, project controls and modal windows are designed for keyboard operation. Reduced-motion preferences are respected where animation is not essential to understanding the content.

Feedback

If you encounter an accessibility barrier, contact hello@zairachrista.com with details of the page and issue.
